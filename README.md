# Scalatello

Scalatello is a Scala implementation of the board game Othello.

This project has been realized for the Programming and Development Paradigms course of the Master's degree in Computer Science and Engineering at the University of Bologna, Campus of Cesena.

## Getting Started

### Prerequisites

To be able to run the application:

* **JRE (Java Runtime Environment)** or **JDK (Java Development Kit)**: Version 8 or higher

Optionally, if you prefer to run the application using the `scala` command:

* **Scala 3**: Version 3.3 or higher

### Start playing

* Go to the ["Releases"](https://github.com/Borgotto/PPS-25-scalatello/releases) section of this repository and download the `.jar` file from the latest release.
* Navigate to the directory containing the `.jar` file.
* Run the application using either of the following commands:

  * Using `java`:

    ```bash
    java -jar <jar-name>.jar
    ```

  * Using `scala`:

    ```bash
    scala <jar-name>.jar
    ```
